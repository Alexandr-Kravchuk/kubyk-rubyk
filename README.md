# Кубик Рубик / Rubik’s Cube

Illustrated last-layer guide in Ukrainian and English. All diagrams are embedded SVG; no build step or external dependencies are required.

- [Українська](https://alexandr-kravchuk.github.io/kubyk-rubyk/)
- [English](https://alexandr-kravchuk.github.io/kubyk-rubyk/en.html)

## Local preview

Run `python3 -m http.server 8000` in this directory and open http://localhost:8000.

## Publishing

GitHub Pages serves the root of the `main` branch. Push changes to `main` to publish them.
